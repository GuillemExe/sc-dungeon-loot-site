# SC Dungeon Loot · web pública

Web estática de [SC Dungeon Loot](https://github.com/GuillemExe), la actividad de Discord para
repartir el botín de las partidas de Star Citizen. Se publica con GitHub Pages.

- `index.html`: portada y créditos.
- `novedades/`: cambios de cada versión.
- `terms/`: condiciones del servicio.
- `privacy/`: política de privacidad.

El código de la app no está en este repositorio.
